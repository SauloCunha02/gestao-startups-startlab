Trilha Extrema

Uma aula. Cinquenta minutos. Do problema ao pitch de 60 segundos, com o relógio correndo. É o percurso mais curto do StartLab — feito para dar o primeiro contato com o método em uma única aula.

O relógio é o professor deste percurso. Quando o bloco acaba, siga em frente mesmo incompleto.

Antes de começar: o que este sprint não é

Três conversas e dois testes em uma aula são um primeiro contato com o método — não são evidência suficiente para afirmar que o problema existe, que o público é aquele ou que a solução funciona. Use para abrir o assunto, para uma oficina avulsa, para uma feira, ou para destravar uma equipe parada. Quando o projeto for valer nota de investigação, faça a Trilha Rápida ou a trilha completa de 12 etapas.

Os 4 blocos

Cada bloco tem tempo fixo. Não dá para voltar: o que ficou incompleto vira anotação para o próximo ciclo.

Acabou o sprint

Levem embora estas três coisas

Uma frase de problema testada contra três relatos. Um papel que duas pessoas tentaram usar. Uma lista do que vocês ainda não sabem — essa é a parte mais valiosa.

Continuar na Trilha Rápida →7 passos, cerca de 6 aulas. Aprofunda o que você acabou de esboçar, com cinco entrevistas e um modelo de negócio. Ir para a trilha completa →12 etapas, 24 aulas. O percurso com avaliação, fichas e portfólio da equipe.

As respostas ficam só neste navegador e neste aparelho, em espaço separado das outras trilhas. Antes de trocar de aparelho, baixe o resumo.
